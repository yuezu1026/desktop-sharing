# MVP · 第一个可发布版本

> 对应 `需求规划-v2-P0P3重构` §1 的 P0，但**只取挡住发版的部分**。
> 安卓被控、电脑控手机、与手机被控同批的音频，在 `S1.md`。需求写明它们不阻塞发版。

## 0. 结束时用户能做什么

同一账号下，Windows 或 macOS 的电脑可以控制另一台 Windows 或 macOS 电脑。Android 手机可以作为**控制端**手持操作，不能作为被控端。可以先走中继立刻看到画面，再在后台升成直连。免费中继时长用尽时，有明示的降级，而不是突然断掉或偷偷降画质。

Web 只做控制端，用一次性质授权码，不登录。

## 1. 建造顺序

顺序是依赖，不是另一套优先级。后面的步骤不能把前面的红线删掉。

1. **账号与设备。** 手机号登录。找回密码和恢复码分开。设备三态、踢下线。取消授权和移除设备是两件事。注销在应用内 3 步可达，30 天可撤销。已登录改密后，其他设备重登，恢复码作废。登录设备管理和「我的设备」不是同一张表。邮箱是可选第二入口，不能单独拿来解锁，也不能解绑最后一个入口。设备数免费版和个人版都是 150 台，不是付费权益。
2. **连接。** 先中继秒连，后台再探直连。中继必须能走 TCP / TLS 443。探测失败不弹窗、不打断当前会话。直连端到端加密；中继只承诺全链路传输加密。对外材料不得写「端到端加密」包打一切。
3. **被控端（仅电脑）。** 识别码和临时密码一眼能抄。首次被控确认含反诈，不得折叠。「拒绝」是主按钮。一键断开，不再问第二次。空闲时近零占用。托盘能断开，且和「退出」不是同一个菜单项。被控端不出现金额、余额、免费中继时长。
4. **画面。** 默认窗口化。等比缩放，两侧黑边，不得改被控端分辨率。全屏只能用户自己开；工具条可以藏，连接方式角标不能消失。
5. **计量与降级。** 裁决在服务端，客户端只展示。免费中继时长默认折叠，用到约八成才出现数字，分钟带「按当前画质估算」。降级四态都能复现，其中「画质已降低」必须写明降到哪一档。两种仅查看分开：资源式画面停在最后一帧；权限式画面还在动。用尽后的出路由用户点开，三条免费路在前，购买在最后。
6. **付钱。** 只卖更多中继时长，不解锁功能。年付 ¥158（约 ¥13.2/月），月付 ¥24 且自动续费。订单确认时固化当时的价格版本，可填发票抬头。支付结果至少覆盖：已开通、未完成、确认中、订单已关闭。确认中不得说成支付失败，不得让用户再付一次。扣款失败不等于终止，不得静默降级，不得自动重试。扣费前 5 日提醒走自有支付渠道，不能只做应用内一条。官网购买页和以后的 iOS 购买页是两套，本阶段不发 iOS 包。收银台和 Apple 支付弹层不是我们的界面。
7. **合规。** 首次连接前说明：中继会转发；直连只报起止，不用于计费、不采画面。实名不是人人先验。触发了才走；没触发不得提示实名。跨账号连接的闸门在被控端确认，不在控制端强制实名。
8. **Android 控制端。** 手持会话：等比、放大镜、双模指针、焦点跟随。顶栏默认只显示链路类型。触控可点区域至少 44px。外接大屏不在本阶段。
9. **运营台最小版。** 内部账号，强制二次验证，不复用用户手机号登录，没有自助注册。3 查（用户、计量、订单）和 3 动作（调时长补偿、封禁加白、退款跳到渠道后台）。计量和用户侧是同一份数据。不造商品管理、成本报表、工单。

连接元数据在本阶段就要能出数：打洞分桶和周活跃远程会话数都靠它。周活跃只计成功建立并持续至少 30 秒的会话，直连和中继同等计入。

## 2. 本阶段明确不做

- 安卓作为被控端，以及电脑控手机。见 `S1.md`。
- 远程音频三合一。需求写明与手机被控同批，不提前塞进 MVP，也不允许静默采音留到以后再补提示。
- iOS 任何包。因此「iOS 不得引导站外支付」在本阶段没有包可查；一旦要发 iOS 包，必须先满足该条，不能带进 MVP。
- 权益对比表、用量明细页、账单发票退款的完整个人中心。续费提醒本身不在此列，它留在上面第 6 步。
- 定价后台和成本台账的管理界面。后端仍必须能按版本固化下单价，不能把 ¥158 写死在客户端。
- 虚拟麦克风 / 虚拟摄像头、高帧率插件、外接大屏、鸿蒙、眼镜。

## 3. 发版前必须关掉的闸门

需求文档把「P0 要做什么」和「缺了就不能发版」分成两张表。MVP 发版看第二张，并按上面的范围裁剪：

- 合规：加密用词、隐私两件事、注销、5 日提醒、实名触发、反诈、一键断开。
- 计量：443 中继、服务端裁决、降级四态、连接元数据能出数。
- 画面：不失真、不默认全屏、全屏角标还在、被控端空闲几乎不占 CPU。
- 报价：TURN 报价未到手只禁止对外写死额度数字，不禁止发版。免费中继 2 GB/月是否成立，看上线后插件实收，不在发版当天改口径。

安卓被控的机型通过率和息屏能否净充电，是 S1 的闸门，不是 MVP 的闸门。
