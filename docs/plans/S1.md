# S1 · 手机被控钩子

> 对应需求里的「P0 内第二优先级」。**不阻塞 MVP 发版。**
> 和安卓被控端同一批的，还有电脑控手机，以及远程音频。拆开做，钩子会断在半截。

## 0. 结束时用户能做什么

父母的安卓手机可以被同一账号下的电脑或手机连上，用来看屏幕、帮忙点。子女更常用电脑来连。连接前每次都要本人确认。手机上不出现金额和免费中继时长。

能听到对方设备在放的声音，也能对着讲。被控端看得到「正在采音」，并能一键静音。静音不是惩罚，不能因为降级就把声音关掉。

## 1. 做什么

**安卓被控端**

- 首次启动授权：屏幕录制、无障碍、通知、电池。不授权不是「不能用」的阻断，未完成的项是降级。
- 主界面：识别码、临时密码、四行授权自检、反诈。允许被连接是开关，不是一颗「再点一次」的主按钮。
- 前台服务通知里可以直接断开，不再二次确认。
- 息屏串流默认关。电池白名单没设，只说明可能被系统停掉，不阻断，也不引导付费。
- 机型分档：已验证、可用但需引导、不支持。不支持时不卖会员。
- 每次连接请求都要人工确认，并显示对方是谁、上次有没有连过。拒绝不得做成比允许更轻的按钮。

**电脑控手机**

- 复用已有的电脑控制端和安卓被控端。新增的是：电脑上看手机画面时仍要等比、不变形，以及把触控语义映射到键鼠。
- 这是获客钩子，不是对外主主张。文案仍是远程桌面，不改成「手机监控」一类说法。

**音频（三件一起）**

- 系统声音从被控端回到控制端。
- 控制端麦克风对着被控端扬声器讲。播放不需要驱动。
- 纯音频模式：关掉画面只传声。这一档不参与「剩余分钟」折算，避免把很少的流量显示成几千分钟。
- 音频算在会话里，不单开一个收费科目。
- 被控端在采音时必须有提示，并能一键静音。不得静默采音。

## 2. 开工前要有数，否则整段降级

- 白名单机型通过率低于 60%，安卓被控整体改到 S2，不带着「稍后修复」发。
- 息屏串流如果采不到真实画面，或充电抵不过耗电，这一能力不进发布说明。不得先上线再补实测。
- 通话声音（微信语音、电话）系统不让采。对外不得暗示支持。
- iPhone 不能做被控端。对外不得写成「也能控父母的 iPhone」。

## 3. 本阶段明确不做

- 免 Root 之外的机型扩容、免每次确认的一键连、横竖屏进阶。那是 S2。
- 虚拟麦克风、虚拟摄像头。那要把远程的声音伪装成本机设备，需要签名驱动，在 S2。
- 息屏串流默认打开。
- 在被控手机上出现任何价格、余额、升级。
