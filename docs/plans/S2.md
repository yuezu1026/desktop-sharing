# S2 · 体验完善

> 对应需求 §1 的 P1。MVP 和 S1 的红线在这里仍然有效，不能为了新功能改回去。

## 0. 结束时多出来的能力

用户能在 iPhone / iPad 上当控制端，能把手机接到有线大屏上用键鼠，能看到每一笔中继用量，能管理订阅和发票。更高画质以插件存在，并且自己封顶，不把免费中继时长一次用完。

## 1. 做什么

**控制端补全**

- iOS 只做控制端。购买只有 App Store。不得出现网页、微信、支付宝、比价。权益对比如果上 iOS，单独一套，不和官网拼在一页。
- 外接显示器：检测到大屏要先问，可以拒绝，可以记住选择。大屏用桌面布局，不沿用手机手持那套。机型不支持有线视频输出时，只说明硬件不行，不引导付费。不做无线投屏。
- 鸿蒙移动端和平板：手持规则与 Android 控制端相同，不把桌面界面缩小贴上去。
- 多显示器完整支持、高 DPI。MVP 只要求能切换显示器。
- 弱网时降分辨率、帧率、画质，且降了必须告诉用户，与 MVP 的「禁止静默降码率」同一条纪律。

**被控端进阶**

- 安卓被控：扩大已验证机型、把息屏串流做稳、横竖屏。仍不默认开息屏，仍不在手机上谈钱。
- 无人值守进阶：多用户切换、锁屏后仍可连。MVP 已有的开机自启和空闲近零占用保持。
- 权限可以收细：只允许看、禁止传文件、限制这一次时长。收权之后，控制端必须是「权限式仅查看」（画面还在动），不能画成「时长用尽、画面冻住」。

**声音与画质插件**

- 虚拟麦克风、虚拟摄像头：让电脑上的微信把远程的人当成自己的麦和摄像头。需要签名驱动。这不是 S1 的「对着扬声器讲」。
- 高帧率影音档：2K60 / 4K60。必须自带流量封顶。购买页写明不做竞技网游的键鼠注入。

**账与后台**

- 权益对比表。免费的项写「免费」，包括手机被控、直连、150 台设备。
- 个人中心：订阅状态分 iOS 和非 iOS 两套；用量明细到每一笔；账单、发票、退款状态。取消续费不得比开通更难。
- 用量明细和运营台读同一份数据。用户侧叫免费中继时长，运营台内部才叫额度。
- 运营台完整版才做商品、报表、工单。MVP 的 3 查 3 动作保持。
- 定价：改价是新增一个版本，不能改已经写进订单的那个数。涨价不追老用户，降价要告知。活动价到期自己回到原价，并提前告知。iOS 价格以 Apple 为准，后台只读。客服不能改价。
- 成本参数同样版本化。TURN 单价、方向系数这些改完，单位成本和免费额度由系统重算，不许手填结果。客服看不见成本。

## 2. 本阶段明确不做

- 眼镜。见 `S3.md`、`S4.md`。
- 邀请返现、优惠券、活动中心、断连时的促销弹窗。
- iOS 被控、通话录音、绕过版权保护、给网游做注入。
- 把无线投屏当成外接大屏的替代方案。
