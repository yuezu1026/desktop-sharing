# S3 · 眼镜桥接

> 对应需求 §1 的 P2，路径 B。有硬件前提，前提不满足就不开工。

## 0. 结束时用户能做什么

眼镜是手机的另一块屏幕和一副耳机。远程桌面仍跑在手机上。眼镜不自己连我们的服务器，也不成为新的被控端。

## 1. 做什么

- 有线：USB Type-C，眼镜要支持视频直出。
- 无线：标准蓝牙，传显示相关的音频和简单输入。
- 触控板或语音，把输入交回手机上的控制端。
- 适用已经能当显示器的眼镜。不承诺某一品牌的私有协议。

## 2. 开工条件

样机能稳定把手机画面送到镜片上，并且输入能回到手机。做不到就停在文档里，不排进迭代。

## 3. 本阶段明确不做

- 眼镜直接连接远程电脑。那是 `S4.md`，而且目前不做工程承诺。
- 把 S2 的有线大屏（手机接到显示器）和本阶段混成一个项目。大屏是手机的桌面模式，眼镜是另一类硬件。
