W1 · 控制端 · 连接与免费中继时长

这是全套线框里最不能省的一组：连接模式指示器是主主张的唯一执行体，降级链四态是「禁止静默降码率」的唯一执行体。
本页 15 个条目 / 18 张图（W1-05 一屏四态 ⇒ 1 条 4 图；W1-06 / W1-06b 为「仅查看」的两种成因，各自独立成条），其中 11 个条目属「缺了就是违反已拍板决策」。
🔴 全页出现的免费中继时长数值均为示意，实际必须后端下发（`商业化与计费设计` §13.5：TURN 报价到手前数值会变）。
术语纪律：免费档配额一律写「免费中继时长」，不写「额度」——「额度」只用于运营台与开发文档；付费买到的时长叫「中继时长」（不加"免费"，见 README §6.1 术语表）。
🔴 计量展示纪律（`[D20]`，本页是执行体之一）：① 任何「剩余 xx 分钟」必须带注脚「按当前画质估算 · 切换画质会变」② 折算取码率地板 2 Mbps（SSOT P18）③ 纯音频模式不参与分钟折算（SSOT P17，改显示 GB）④ 扣减永远按 GB。详见 W1-04 ④~⑦。
🔴 全屏 / 沉浸式纪律（`[D22]`，本页 W1-11 是执行体）：全屏仅由用户显式触发；工具条自动隐藏，但 🔴 连接模式指示器不得消失（降级为画面右上角的极简角标）；退出全屏恢复进入前的窗口尺寸与位置。详见 v2 §2.4.1 与 W1-11。

W1-05 · 🔴 降级链四态（缺任意一态 = 违反「禁止静默降码率」）

按顺序看：A 预警 → B 转直连（自动，用户无需操作） → C 码率已降（必须明示到具体档位） → D 终止前告知（给倒计时与选择）。 四态都不出现金额，只说明「发生了什么」和「下一步做什么」。
四态各自有锚点，可单独引用： A · B · C · D。
