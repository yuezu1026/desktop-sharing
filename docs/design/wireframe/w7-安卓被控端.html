W7 · 安卓被控端

W2 把「被控端」画成了 PC 语义（UAC / WoL / 编码器 / 多显示器）， 但 v2 §3.6「移动端作为被控端」自 2026-09-14 起就是 P0 能力（`[D8]` 差异化钩子 + `[D10]` 已把「PC→手机」提升到 P0）。
手机当被控端与 PC 当被控端有三个不可回避的差异：① 免 Root 能力必须由人在手机旁逐项授权；② 系统强制要求前台服务通知；③ 各厂商 ROM 的省电策略决定「被连接」能不能持久。
本页 7 个条目 / 7 张图，全部为 P0（其中 W7-07「收到连接请求」由 `[D27]` 跨帧一致性收口补入）。

🔴 贯穿本页的一条铁律：本页是「手机被控免费」这个钩子的兑现面 —— 任何让被帮助的一方感到「要花钱 / 被推销 / 被瞒着」的界面，都会让整条产品链路归零（ 商业化与计费设计 §13.4 红线②）。
