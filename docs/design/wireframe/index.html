4. 评审建议顺序

不要按屏评审，按流程评审（README §4 有 7 条流）： 流 1 首次连接 → 流 2 降级四态 → 流 3 被控端授权 → 流 4 退款 → 流 5 注销 → 流 6 运营台内部操作（登录 → 强制 2FA → 3 查 → 3 动作 → 离职回收）→ 流 7 支付与到账（订单确认 → 唤起 → 结果四态）。
按流走，缺屏会自己暴露出来；按屏走，缺的流程永远看不出来。
🔴 流 7 是最后补上的：前六条流都只走到「点下按钮」为止， 而钱出去之后会发生什么，此前一屏都没有（[D25]）。
