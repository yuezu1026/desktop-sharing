Brand · App Icon · Splash

一眼是「连到另一台电脑」，不是又一个蓝按钮。

图标不写字、不画地球、不画锁。图形是双视口：退后的是远端桌面轮廓，靠前的是你正在看的窗口。 主色只用品牌蓝渐变（`--brand`），绿色留给产品里的「直连」状态，不进图标。 本稿是视觉规格，不新增产品名或Slogan。

16px 仍成立 托盘与任务栏只靠两个错位矩形辨认。细节任务栏在小尺寸可省略，大尺寸才出现。
状态色不进图标 ok / warn / err 只出现在会话内。图标恒为品牌蓝，避免「图标绿 = 已直连」的误读。
安全区 外圈虚线 ≈ 平台 mask 外边；内圈实线 ≈ 关键图形安全区。导出 1024 时按平台模板裁切。
启动页克制 只放图标 + 产品名「远程桌面」。不放价格、剩余时长、升级文案。被控端冷启动同样不加金额。
