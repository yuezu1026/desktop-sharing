## 1. 视觉论点

产品被相信，靠的是「这次是直连还是中继」说得明白，不是靠促销色。色板是**语义 Token**，不是装饰色名。

| Token | 用途 |
|---|---|
| `--brand` | 品牌强调、链接、侧栏选中软底；登录 / 注册主按钮；「允许被连接」开关开态 |
| `--ok` | 直连、在线、「重新尝试直连」；日常「连接」主按钮；不用于购买，也不用于「允许被连接」 |
| `--warn` | 中继这一事实（不是警报）；余量不用红色喊 |
| `--err` | 注销、删除；不用于断开，也不用于余量 |
| `--text` 实心 | 购买主动作，以及反诈页的「拒绝」 |
| `--surface2` / `--surface3` | 侧栏与次级面（不再用墨绿大色块） |
| `--bg` + aurora | 页面底；亮/暗双主题见 `tokens.css` |

字体用系统界面字体（Segoe UI / 苹方 / 微软雅黑）。识别码用等宽字体（`--mono`），方便念和抄。各页右上角可切暗色。

品牌图形是**双视口**（远端轮廓 + 近端实心窗），规格见 `h0-品牌图标.html`。主图标只用 `--brand` 渐变；ok / warn / err 不进图标与启动页。

## 3. 视觉层必须守住的红线

- 控制端状态栏不放「升级会员」。指示器默认不显示剩余分钟。
- 转直连引导页不出现购买。
- 被控端（含安卓）不出现金额、余额、充值、免费中继时长。
- 确认控制时，「拒绝」是唯一实心主按钮，「允许本次」同尺寸描边。
- 免费能力显式标「免费」。iOS 购买页不出现微信、支付宝、官网、比价。
- 手持顶栏默认只有链路类型；「免费中继时长」是点开才展开的入口。
- 触控可点元素视觉高度 44px；桌面按钮不低于 36px。
