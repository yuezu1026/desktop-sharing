## 1. 视觉论点

产品被相信，靠的是「这次是直连还是中继」说得明白，不是靠促销色。

- **纸** `#F3EFE7`：页面底，避开通用冷灰 SaaS。
- **墨绿** `#172420`：控制端导航。安静，不抢设备卡片。
- **青绿** `#0F6E5C`：直连、在线、日常主按钮。不是「去购买」。
- **琥珀** `#8A4E0F`：中继这一事实。余量不用红色喊。
- **墨色实心**：反诈页的「拒绝」。安全出口才是亮着的按钮。
- **赤** `#9D3B32`：只留给真正的破坏，不拿来做余量条。

字体用系统界面字体（Segoe UI / 微软雅黑）。识别码用等宽字体，方便念和抄。

## 3. 视觉层必须守住的红线

- 控制端状态栏不放「升级会员」。指示器默认不显示剩余分钟。
- 转直连引导页不出现购买。
- 被控端（含安卓）不出现金额、余额、充值、免费中继时长。
- 确认控制时，「拒绝」是唯一实心主按钮，「允许本次」同尺寸描边。
- 免费能力显式标「免费」。iOS 购买页不出现微信、支付宝、官网、比价。
- 手持顶栏默认只有链路类型；「免费中继时长」是点开才展开的入口。
- 触控可点元素视觉高度 44px；桌面按钮不低于 36px。
