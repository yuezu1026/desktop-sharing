## 一、核心体验需求：极简、便捷与快速

个人消费级产品的首要痛点是"配置繁琐"与"连接慢"。产品必须做到开箱即用：

1. **一键安装与统一账号**：摒弃复杂的IP、端口映射等网络配置，所有设备支持一键安装。用户只需注册并登录同一个账号，设备即可自动绑定并出现在设备列表中，实现跨系统无缝互控。

2. **极速连接与低延迟**：针对个人办公与娱乐场景，优化数据传输算法，实现超低延迟（如低于15ms甚至3ms），确保操作与画面反馈的极致流畅。

3. **网页端（Web）免安装直连**：针对临时借用电脑的场景，提供基于浏览器的Web端连接。用户无需在临时设备上安装完整客户端，通过网页登录即可快速发起远程控制。

## 二、跨平台生态需求：全场景无缝覆盖

为了覆盖个人用户的多样化设备，产品需实现全景生态互通：

1. **主流系统全覆盖**：支持 Windows PC、MacBook、Linux 服务器，以及 iPhone、Android 手机的全平台互控。

2. **深度适配鸿蒙（HarmonyOS）生态**：针对鸿蒙移动端和平板进行专项优化。例如，提供"模拟触屏"和"模拟鼠标指针"两种模式；支持双指缩放画面、单指拖拽，解决手机远控时键盘遮挡输入框的痛点，确保触控操作精准不误触。

3. **跨端体验一致性**：实现共享剪贴板（本地复制，远程粘贴）、自动适配不同系统的键盘快捷键（如Mac的Command与Win的Ctrl自动映射），让用户无需改变操作习惯。

## 三、智能眼镜与手机融合需求：灵活接入，全场景覆盖

智能眼镜作为远程桌面的延伸终端，是极具差异化的创新场景。考虑到当前智能眼镜的算力与功能有限，产品采用"双路径接入"策略，确保在任何硬件条件下都能获得良好的远程桌面体验：

### 路径A：智能眼镜直连远程桌面

当智能眼镜具备足够的算力和系统开放性时，支持眼镜直接作为远程桌面客户端：

1. **有线直连与电脑模式**：通过 USB Type-C 接口将智能眼镜直连手机或平板。支持将手机画面投射到眼镜上，并切换至"电脑模式"（呈现类似PC桌面的多窗口布局），满足移动办公需求。

   > ⚠️ **主次澄清（决策 D5）**：手机**不接任何外接屏时，手机单屏就是唯一可用的控制方式**，这是**默认情况** ⇒ ”手持单屏“才是主路径与指标基线；本条的“电脑模式/外接大屏”是 **P1 增强**，**不得写成主路径**。详见 v2 §2.3。

2. **无线投屏与音视频协同**：支持 Miracast 等无线投屏协议，将手机或PC画面流转至眼镜。同时支持音视频分离协同（例如手机投屏至大屏时，声音保留在眼镜端），提升私密性与沉浸感。

   > ⚠️ **边界修正（决策 D5）**：若“无线投屏”指的是**远控画面的输出**，则**不做承诺** —— Miracast / 投屏会多一跳编码 + 两跳传输，在已有延迟上再叠 50–150 ms 并二次损失画质；**远控画面输出仅承诺 USB-C → HDMI / DP 有线直出**。眼镜端的本地镜像不受此限。

3. **AI 眼镜直连与语音操控**：支持智能眼镜直接与 Windows PC 配对，用户可在镜片内查看电脑通知、日历提醒，并通过语音指令远程操控电脑应用（如"打开PPT第5页"），实现真正的解放双手。

### 路径B：手机桥接智能眼镜（兼容fallback方案）

考虑到当前智能眼镜的功能相对较弱，不足以独立运行完整的远程桌面客户端，产品同时支持"手机桥接"模式：

1. **手机作为桥接中枢**：智能眼镜通过有线（USB Type-C）或无线（蓝牙/Wi-Fi）方式连接手机，手机运行远程桌面客户端并建立与目标电脑的远程连接，眼镜仅作为手机的"显示与音频输出设备"。远程桌面的画面投射到眼镜上，操作指令通过眼镜的触控板或语音输入回传至手机，再由手机转发给远程电脑。

2. **无缝降级体验**：用户无论是在办公室佩戴眼镜使用，还是在通勤路上摘下眼镜，远程桌面的连接都不会中断，控制权始终在手机端，体验平滑过渡无感切换。

### 手机独立远程连接（核心能力）

手机本身即为功能完备的远程桌面终端，不依赖智能眼镜即可独立使用：

1. **随时随地远程桌面**：用户无需任何额外硬件，打开手机上安装的客户端即可直接连接目标电脑，支持锁屏界面快捷启动（通过手机指纹/通知栏快捷入口）。

2. **多场景适配**：针对手机小屏幕优化显示比例与触控交互，支持分屏模式（一侧显示远程桌面，一侧显示本地应用），提升移动办公效率。

## 四、安全与隐私防护需求：消费级的安心保障

个人用户同样对隐私极度敏感，产品需内置多重防护机制：

1. **端到端加密与多重验证**：采用 AES-256 等高强度加密算法保护链路安全，支持双重验证与设备授权，防止账号被盗用。
   > ⚠️ **已否决（D1）**：中继明文可见，「端到端加密」不可宣称。正确表述见 v2 §6.1：**「全链路传输加密；P2P 直连时端到端加密」**。

2. **隐私保护模式**：在远程控制期间，提供"隐私屏"或"黑屏保护"功能，自动隐藏被控端的桌面壁纸或锁屏，防止本地人员窥探敏感信息。

3. **动态权限管理**：支持精细化的权限控制（如仅允许观看、限制文件传输等），并在每次连接时保留全链路操作日志，确保行为可追溯。

## 五、便捷认证需求：指纹一键登录

传统远程桌面每次连接都需要手动输入账号密码，体验割裂。引入生物识别认证后，可实现真正的"无感登录"，让用户在任意场景下秒级接入远程桌面：

1. **手机端指纹一键登录**：在被控端手机上安装客户端后，用户只需通过手机指纹（或面容）验证，即可自动生成一次性加密令牌完成登录授权，无需记忆和输入复杂密码。首次连接新设备时，通过指纹快速授权信任该设备，后续免密直连。

2. **客户端指纹一键登录**：在 Windows/Mac/鸿蒙等桌面客户端中，支持绑定设备指纹（如硬件ID、TPM芯片标识等），实现客户端级别的自动信任。用户打开客户端即可直接连接目标设备，彻底告别密码输入流程。

3. **智能眼镜端无感认证**：针对智能眼镜场景（无实体键盘），指纹/面容一键登录尤为重要。用户在眼镜端点击"连接我的电脑"，通过本地生物识别验证后瞬间建立远程会话，让智能眼镜作为"第三屏"的实用性产生质的飞跃。

4. **安全机制说明**：指纹/面容数据始终存储于设备本地安全芯片（TEE）中，不会上传至云端或服务器。登录时客户端通过指纹验证后生成有时效性的一次性加密令牌（Token）发给服务器进行校验，比传统明文密码传输更安全，可有效防止撞库和暴力破解攻击。

## 总结

这款个人消费级远程桌面产品的核心竞争力在于 **"全平台无缝互控"** 与 **"灵活的设备接入策略"**。产品以手机为核心终端 ⚠️ **【已否决，决策 D3：控制端既可以是手机也可以是 PC；长时会话主力是 PC→PC。正确表述为「PC 为被控主体，手机覆盖 PC 触达不到的时段」；~~主差异点改为「手机作为被控端」~~ ⇒ 决策 D8 再修正：主战场 = 远程办公（控制电脑桌面），手机被控 = 差异化能力 / 获客钩子（非主主张）】**，支持手机独立远程连接桌面，同时通过"直连"与"手机桥接"双路径兼容智能眼镜等新兴穿戴设备，确保在任何硬件条件下都能获得流畅的远程桌面体验。辅以极简的Web端与账号体系降低使用门槛，结合鸿蒙生态的专属优化、指纹一键登录的无感认证 ⚠️ **【已否决：硬件 ID 免密登录，安全漏洞】**，以及端到端加密的安全保障 ⚠️ **【已否决，决策 D1：中继明文可见，禁止宣称 E2E】**，能够精准切中现代用户在混合办公、移动娱乐等场景下的刚需。
